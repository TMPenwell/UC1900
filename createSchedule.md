# Use Copilot to Help Create Your Schedule
#### [Made by Tasha Penwell with Scribe](https://scribehow.com/o/tRYqoVDKQseRHf1hnUYbNQ/viewer/Use_Copilot_to_Help_Create_Your_Schedule__xZi6zu9WRqucbBPxZ_j0Sg)
This guide shows how to use Copilot to turn screenshots of your calendars into a personalized, conflict-free schedule by iteratively prompting and refining results. It highlights adding personal work habits to get better time placement and explains how to export the final plan as a universal .ics file you can import into any calendar app. It saves time and ensures your classes, work, and peak productive hours are respected.

1\. Capture screenshots of your calendars - this can be your class schedule available at your student center, your work schedule, etc.  

&nbsp;

Write a prompt based on your needs.  You can see the one I used below is: 

*compare my class schedule and work schedule on Google Calendar. help me create a schedule where i have time to work on the classes I'm taking*

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-09-04/74669fae-3d2e-4015-8f2d-8bc452fbef80/user_cropped_screenshot_e518de36098c4a35a64a9436b1139758_text_export.jpeg)


2\. Review the results and make needed adjustments by re-prompting. 

One example, I'd recommend is adding some personal characteristics about yourself. One example is showing below.

 *okay, i'm best cognitively in the morning. in the evenings is better for creative thinking for me*

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-09-04/08b854c5-9592-460d-89af-ebd05b19e744/user_cropped_screenshot_da9ecf20d9534fcb9d243f69e91da338_text_export.jpeg)


3\. Continue to refine and re-prompt as needed. 

Once you have a schedule that appears to work for you, we're going to ask it to create an ics file with a prompt *can you create an ICS file?*

Note: A .ics file (iCalendar file) is a universal calendar text file that stores event details like meeting times, locations, and descriptions so you can share them across different calendar apps.

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-09-04/2826a561-e4c2-48dd-bfcf-3a6d24659b8f/user_cropped_screenshot_88d52b45f790473c967110d728d16cc7_text_export.jpeg)


4\. Download the .ics file

![](https://colony-recorder.s3.us-west-1.amazonaws.com/files/2026-09-04/114e058f-12e3-49bf-a42f-eddfd5e0932b/action-a4dad2e79a8a4acc9f6df3c7437fdc46_1b1dc91707634d0eb388d917a853c079_text_export.jpeg)








# Upload ICS File Into Outlook Calendar
#### [Made by Tasha Penwell with Scribe](https://scribehow.com/o/tRYqoVDKQseRHf1hnUYbNQ/viewer/Upload_ICS_File_Into_Outlook_Calendar__UWDAMyfhQrmge5ztUv30RQ)
This guide quickly shows how to import an .ics file into Outlook and update imported events. It walks through uploading the file to a specific calendar, adding it, then locating and editing a recurring event to add a clear description. Follow it to save time and ensure imported events include the notes and reminders you need.
